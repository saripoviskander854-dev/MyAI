Простая реализация перцептрона на Python.

Перцептрон — это базовый искусственный нейрон. Он получает несколько входных сигналов, умножает их на веса, складывает результаты и выдаёт выход (0 или 1). Это простейшая модель для задач классификации.

Входы — числа, которые подаются нейрону. Веса — важность каждого входа: чем больше вес, тем сильнее вход влияет на результат. Bias — сдвиг, который позволяет нейрону активироваться даже при нулевых входах, смещая порог срабатывания.

Взвешенная сумма считается как сумма произведений входов на веса плюс bias.

Step Function — функция активации, которая превращает взвешенную сумму в выход: если сумма больше или равна нулю, нейрон выдаёт 1, иначе 0. То есть нейрон «включается» при неотрицательной взвешенной сумме.
